### 1-2. 사례별 상세 분석

#### ① Hallow — 시즌 캘린더가 성장 엔진

**숫자**
- 2025년 앱스토어 순수익 약 $40M (Appfigures 추정) [18]
- 사순절(Ash Wednesday) 하루 다운로드 **263,000건** — 평소 일일 평균 10,000의 **26배** [7]
- 2026년 2월 누적 다운로드 120만 (평소 월 28만 대비 4배) [7]
- 매출 스파이크는 다운로드보다 **1~2개월 뒤** (체험→유료 전환) [7]
- 누적 30M 유저, 10억+ 기도, 150개국 [26]
- 14일 무료 체험 + 첫 달 50% 할인 [27]

**성공 메커니즘**
1. **불교력에 대응하는 시즌 캘린더**: 사순절(40일), 대림절(4주), 성탄절 → 사용자에게 "지금이 특별한 시기"를 상기. 챌린지(#Pray40) + 한정 콘텐츠 + 한정 스탬프.
2. **오디오가 핵심 제품**: 매일 업데이트되는 오디오 묵상 + 수면 성경 이야기 + 유명인 내레이션 (마크 월버그, 조나단 루미). 오디오 품질 = 결제 이유.
3. **B2B Parishes**: 5,000+ 교구에 단체 라이선스 판매 → 안정적 수익 기반 [16].
4. **다국어(스페인어·포르투갈어·폴란드어)**: 2023년 스페인어 론칭 후 라틴아메리카/유럽 다운로드 +40% [26].
5. **커뮤니티**: 그룹 기도, 공유 기도 플랜 → 네트워크 효과로 이탈 감소.

**마음정원 적용**
- **부처님오신날**(음력 4월 8일, 보통 5월), **정초 기도**(1월), **백중**(음력 7월 15일), **동지**(12월), **단풍 시즌**(10~11월), **신년 해돋이**(1월 1일) → 6~8주 전에 시즌 콘텐츠·한정 스탬프·챌린지를 준비.
- "21일 108 참선 챌린지", "7일 새벽 기도 챌린지" 같은 **시즌 도전 과제** 추가.
- 오디오: 사찰 상세에서 오디오 가이드 자동 재생 (GPS 도착 시).
- 다국어: 영어판(외국인 템플스테이 수요 5.5만+/년 [13]).

#### ② Finch — 부트스트랩으로 $30M ARR

**숫자**
- ARR $30~40M, VC 투자 $0 [19]
- iOS 평점 4.95/5 (550K+ 리뷰, 85% 5성) [19]
- D1 잔존 54%, D7 잔존 37% → Duolingo(D1 51%·D7 35%)·Calm·Headspace보다 높음 [5]
- 월 다운로드 40~60만, iOS Health & Fitness #8 [19]
- 36단계 온보딩 (점진적 기능 발견) [28]
- 위젯 → "always with you" 감각 [5]

**성공 메커니즘**
1. **진행형 발견 (Progressive Discovery)**: 처음에는 새에게 이름을 붙여주고, 완료한 과제에 따라 새가 모자를 찾고, 탐험을 떠남. 기능을 한꺼번에 보여주지 않고, 감정 상태에 맞춰 점진적으로 공개 → "처음부터 부담 없음".
2. **위젯 = 리텐션 엔진**: 아침 체크인 → 저녁 반성 루틴을 위젯이 수동 노출. 사용자가 직접 설치한 표면이라 스팸 아님 → D30 리텐션 Duolingo 이상 [5].
3. **초대·선물**: 친구를 초대하면 인앱 화폐 + 독점 아이템 → 초대 루프.
4. **소프트 페이월**: 무료로 대부분 사용 가능, 유료는 추가 꾸미기·테마·고급 분석.

**마음정원 적용**
- **진행형 온보딩**: 처음 3문항(관심 분야·나이대·거주 지역) → 맞춤 사찰 3곳 추천 → 첫 GPS 인증 또는 스토리 읽기 유도 → 페이월.
- **위젯**: PWA 한계 보완 — 카카오톡 알림톡/푸시 + 모바일 브라우저 "홈 화면에 추가" 유도 → 잠금화면/홈에 염주 스트릭 표시.
- **초대·선물**: "순례 동행 초대" → 친구가 설치하면 양쪽 보상.
- **평점**: 4.95/5가 핵심 경쟁력 → "앱이 도움이 되셨다면 리뷰 부탁" 시점 최적화.

#### ③ Duolingo — 스트릭이 만든 습관

**숫자**
- 일일 활성 유저(DAU) 3,200만+, 구독자 1,270만 [20]
- **7일 스트릭 → 다음 날 잔존 2.4배** [4]
- **위젯 설치 유저의 50%가 6개월+ 스트릭** [6]
- **위젯 도입 → 유저 커밋먼트 +60%** [6]
- 10M+ 유저가 365일+ 스트릭 유지 (2026) [4]
- 600+ 스트릭 실험 실행 [4]
- 55%의 3일 체험 취소가 Day 0에 발생 [3]
- 상위 등급(Max)은 전체 유료의 8%에 불과 (콘텐츠 충분 후 도입) [29]

**성공 메커니즘**
1. **손실회피**: 스트릭이 길어질수록 끊기 싫어하는 심리가 강해짐. Duolingo 자체 데이터: "7일 스트릭 유저의 다음 날 잔존 2.4배" [4].
2. **위젯 = 수동적 리마인더**: 알림(Active) vs 위젯(Passive). 위젯은 사용자가 설치하므로 스팸 피로 없이 하루 종일 노출. Duolingo 위젯은 10시(아침) → 22시(마감 직전)까지 분위기가 바뀜(편안→불안) [6].
3. **프리즈·복구**: 스트릭 동결 아이템 → 하루 안 켜도 유지. 30일+ 스트릭 잃은 유저에게 이벤트형 복구 제공 [4].
4. **친구 스트릭**: 친구와 같이 매일 완료 → 사회적 압박 + 재미.

**마음정원 적용**
- **염주 스트릭**: 매일 기도/염주/명상/한 구절 → 스트릭. 프리즈 1회 무료(무료), 추가 프리즈 유료.
- **위젯 대체**: PWA 설치 + 카카오톡 채널(아침 "오늘의 한 구절" + 저녁 "염주 스트릭 마감 2시간 전").
- **친구 스트릭**: 같이 순례하는 친구 → "함께 염주" 연동.
- **상위 등급**: 나중에 — 지금은 콘텐츠가 적으므로 무료 핵심 + 플러스(심화)만.

## 3. 추가하면 좋을 것 A — 전환 (돈 되는 순간 만들기)

### A1. 온보딩 3문항 + 맞춤 추천 → Day 0 첫 가치

2. "어디에 계세요?" (시·도 또는 GPS) → 가까운 사찰 추천
3. "어떤 분과 함께?" (혼자·가족·친구·연인) → 동행 스타일

→ "OO님, 오늘 가기 좋은 사찰 3곳" + 첫 사찰 상세 → 전설 읽기 or GPS 인증 유도

**근거**: Finch 36단계 온보딩 = 진행형 발견 [28]; RevenueCat 상위 10% 페이월 38.7% [2]; Duolingo Day 0 전환 ~50% [3]

**페이월 지점**: 첫 전설 1편 완독 후, 또는 첫 GPS 인증 후 → "더 많은 이야기와 오디오를 보시겠어요?" → 플러스 7일/14일 체험 시작

| **17~32일** | **42.5%** | ✅ 최적이나 한국 법 리스크 검토 필요 |

### D1. 웹 결제 우선 — 수수료 3% vs 30%

**예시: 연간 39,000원 × 100명**

| 경로 | 총매출 | 수수료 | 순수익 | 차이 |
|---|---|---|---|---|

| **웹 토스페이먼츠 3%** | 3,900,000원 | 117,000원 | **3,783,000원** | **+1,053,000 (+38.6%)** |

**단, VAT 미포함**: 39,000원의 공급가 35,455원 기준으로 실제 마진 계산 필요.
→ **연간 100명만 유치해도 웹 결제 전환으로 연 100만원+ 추가 수익**

**실천 방법**
1. 웹사이트(PWA)에서 토스페이먼츠/Stripe로 결제
2. 결제 완료 → 계정 생성 → 앱에서 로그인 → 플러스 상태 동기화
3. iOS/Android 앱은 IAP도 병행 (스토어 정책 준수)
4. 웹 전용 연간 할인(29,000원)으로 웹 결제 유도

**RevenueCat 데이터**: 웹 결제 시 **85~97% 수익 보유** vs 스토어 70~85% [1]. 웹 구독자 1개월 잔존 **84.5%** vs 앱 구독자 **48.2%** (의도적 구매) [39].
