### 2-2. 핵심 발견 5가지

1. **"핵심은 무료, 깊이와 편의는 유료"가 신앙·명상 앱의 공통 문법**입니다. Hallow는 성경·묵주기도 같은 핵심 기도를 무료로 두고 Dailies 전체·수면·음악·챌린지·오디오북만 구독으로 묶었고, 그 결과 2025년 순매출 약 4,000만 달러(추정)를 냈습니다. 마음정원도 기도 안내·예절·순례 인증은 무료, 심화 이야기·오디오·코스·오프라인만 유료로 둡니다.
2. **연간 구독이 주력**입니다. 마보(47,000원), Calm(59,000원), Headspace(89,000원), Hallow(99,900원) 모두 연간을 앞에 둡니다. 마음정원은 사용 빈도가 이들보다 낮으므로 연 39,000원이 상한선에 가깝습니다.
3. **시즌 이벤트가 매출 피크를 만든다**: Hallow는 사순절 #Pray40으로 재의 수요일 하루 26.3만 다운로드, 전환은 체험 종료 뒤인 3~4월에 일어났습니다(2024년 3월 순매출 1,000만 달러). Pokémon GO는 투어 주말 이틀에 1,980만 달러. → 마음정원은 **부처님오신날, 단풍철, 새해 일출, 수능 100일 기도 시즌**에 맞춘 한정 스탬프·코스를 운영합니다.
4. **2030은 건당 소액 결제에 익숙**합니다. 포스텔러는 이용자의 85%가 2030이고 콘텐츠 5%만 유료(건당 3천~2만 원)로 2023년 매출 100억 원 이상, 흑자를 냈습니다. → 구독이 부담스러운 사람에게 2,900~4,900원 단품을 엽니다.
5. **여행 앱의 대표 유료 기능은 오프라인**입니다(AllTrails Plus, Duolingo Super). 산중 암자·적멸보궁은 통신이 약해 마음정원에도 꼭 맞는 유료 기능입니다.

## 6. 리스크와 대응

1. **신앙 상업화 논란**: 기도 안내·예절·출처는 항상 무료. "소원 성취", "기도발 보장" 같은 문구 금지, 모두 "전해지는 이야기"로 표기. 부적·기도 대행·소원카드류 상품은 만들지 않음. 사찰 협의 없이 사찰명·사진을 유료 상품 이름에 쓰지 않음.
2. **표시광고법·전자상거래법 (다크패턴)**: 2025-02-14 시행 개정 전자상거래법은 무료 체험 후 유료 전환·정기결제 금액 인상 때 **전환 30일 이내에 일시·변동 전후 가격·결제 방법에 대한 명시적 동의**를 받고 취소 방법을 고지하도록 했고(최초 계약 때 포괄 동의만으로는 안 됨), 동의가 없으면 자동 전환하면 안 됩니다. 취소·탈퇴 방해, 잘못된 계층구조(선택지 크기·색 차별), 반복 간섭, 특정 옵션 사전 선택도 금지됩니다(위반 시 과태료 1차 100만 원~). 2025-10-24부터 해석기준이 담긴 소비자보호지침이 시행됐습니다. → 데모에서 체험 종료 시 자동 전환 안 함, 해지 버튼을 같은 화면에, 팝업 자동 노출 없음. 출시 전 **법률 검토 필수**(청약철회 7일·디지털 콘텐츠 예외 표시 포함).
3. **인앱결제 수수료**: 애플은 한국에서 인앱결제 30%(소규모 사업자 15%), 제3자 결제 26%(방송미디어통신위원회 제재 절차 진행 중). 구글은 2026-12-31부터 한국에 새 수수료(구독 10%+결제 수수료, 연간 첫 100만 달러 10%)를 적용합니다. → 연 39,000원 기준 수수료 10~15%를 빼면 약 33,000~35,000원(부가세 별도 고려)으로 잡고, 웹 결제 병행 여부는 정책 확정 후 결정.
4. **위치정보법**: GPS 인증은 위치기반서비스 사업 신고·위치정보 이용 동의 필요.
5. **콘텐츠 정확성**: 전설·연혁·기도 안내는 출처 표기 + 불교학·문화유산 전문가 감수 후 유료화. 사찰 개방시간·행사 변경은 제보 + 정기 검수.
6. **사찰·종단 협의**: 템플스테이 제휴는 한국불교문화사업단(템플스테이 통합예약)과 협의. 사찰 사진·설화 사용 허락.
