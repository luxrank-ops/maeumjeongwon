### 1-4. 핵심 발견 6가지

1. **사람들은 "정보"보다 "정리된 깊이 + 습관 + 편의"에 돈을 낸다.** 롱블랙(매일 1편, 24시간 한정)은 월 4,900원으로 MAU 20만을 넘겼고 완독률이 약 80%입니다 [1]. 사찰 정보 자체는 공개돼 있어도, **잘 쓴 연재 스토리**는 팔립니다.
2. **입문은 무료, 심화는 유료.** Calm·Headspace·Hallow 모두 입문·핵심을 무료로 두고 깊이를 팝니다. 마음정원은 스토리마다 **첫 장 무료**, 나머지 유료.
3. **여행 앱은 연간 상품이 강하고, 월간은 약하다.** 여행 카테고리 연간 첫 갱신율 40%로 카테고리 1위, 월간은 53%로 중간 [13]. → **연간 39,000원을 기본 선택**으로(단, 사전 선택은 다크패턴 소지 → 데모는 사용자가 고른 값을 기억만 함).
4. **전환이 늦게, 시즌에 일어난다.** 여행 카테고리 전환의 28.2%가 설치 6주 뒤 [12]. → 단풍·설경·부처님오신날 직전 **시즌 리포트·한정 스탬프**가 전환 계기.
5. **구독이 싫은 사람은 건당 소액을 산다.** 포스텔러는 콘텐츠의 5%만 유료(건당 3천~2만 원)로 흑자 [v1-D], komoot는 지역팩 단품 [v1-A]. → **콘텐츠 상점**을 구독과 병행.
6. **광고는 보조 수단.** 한국 보상형 eCPM은 앱·날짜별 편차가 크고 [14][15], 콘텐츠 앱 단가는 확인 못 함. 광고는 "무료 이용자가 유료 콘텐츠를 맛보는 통로"로만 씁니다.

### 2-5. 보상형 광고 규칙

- 위치: 잠긴 심화 스토리 하단 **한 곳만**. 사찰 상세·기도 안내·지도에는 광고 없음, 배너·전면 광고 없음.
- 보상: 그 스토리 1편 24시간 열람. 하루 2회(반복 시청 단가 하락·남용 방지 [16]).
- 광고 카테고리 차단: 종교 단체 홍보, 점술·부적·기도 대행, 도박·대출·성인, 다른 종교 비방. (AdMob 광고 검토·차단 기능 [17])
- 13세 미만 대상 맞춤 광고 금지, 맞춤 광고 동의(ATT 등) 거절해도 기능 동일.

### 2-6. 윤리·콘텐츠 가드레일

1. **직접 만든 것만 판다.** 사찰 공식 사진·문구·안내문, 영상 클립, 남의 글 문장을 쓰지 않음.
2. **사실 vs 전해지는 이야기 구분.** 설화·일화 단락은 화면에 '전해지는 이야기' 라벨. 효험·예언·"기도발 보장" 문구 금지.
3. **출처 표기.** 편마다 참고 자료 링크. 유튜브(예: 풍생풍사TV)에서 얻은 정보는 **내 말로 다시 쓰고 채널명·영상 링크로 출처 표기**, 영상 임베드·캡처·자막 전재 금지.
4. **AI 사용 원칙.** 설화·연혁·출처를 AI로 지어내지 않음. 글쓰기 보조를 쓰더라도 사실은 1차 자료로 확인하고 사람이 편집. 오디오는 출시판에서 사람 녹음(데모만 기기 TTS).
5. **사진.** 직접 촬영, 또는 상업 이용 가능한 라이선스만: **공공누리 제1유형**(출처 표시 시 상업·변형 허용 [18]) 또는 CC BY/CC BY-SA. 촬영 금지 구역 사진은 쓰지 않음.
6. **신앙 존중.** 기도 안내·예절은 영구 무료. 부적·기도 대행·소원권 같은 '효험 상품' 없음.

## 5. 유닛 이코노믹스 시나리오 (모든 입력값은 「가정」)

**공통 가정**
- 가격은 부가세 포함 → 순매출 = 가격 ÷ 1.1 × (1 − 스토어 수수료).
- 스토어 수수료: **15%**(애플 소규모 사업자 프로그램·구독 수수료 기준) 또는 **30%**(일반) 두 경우로 계산 [v1-E].
- 구독 ARPPU(월, 총액) = 연간 비중 × 3,250원 + 월간 비중 × 4,900원.
- 단품 평균 가격 3,600원(「가정」: 상점 가격 믹스).
- 광고 수익 = 무료 MAU × 광고 시청자 비율 × 1인 월 시청 수 × eCPM ÷ 1,000 (광고 매출에는 부가세·스토어 수수료 미적용).
- 1년 동안 평균 MAU가 유지된다고 단순화(성장 곡선·이탈 미반영).

| 입력(「가정」) | 보수 | 기준 | 낙관 |
| --- | ---: | ---: | ---: |
| 1년 평균 MAU | 5,000 | 20,000 | 60,000 |
| 유료 구독자 / MAU | 1.0% | 2.0% | 3.5% |
| 연간 플랜 비중 | 60% | 70% | 75% |
| 월 단품 구매자 / MAU | 0.5% | 1.0% | 1.5% |
| 광고 시청자 / 무료 MAU | 10% | 15% | 20% |
| 1인 월 광고 시청 | 3회 | 4회 | 6회 |
| 보상형 eCPM | 2,000원 | 5,000원 | 9,000원 |

| 결과 | 보수 | 기준 | 낙관 |
| --- | ---: | ---: | ---: |
| 유료 구독자 수 | 50명 | 400명 | 2,100명 |
| 구독 ARPPU(월, 총액) | 3,910원 | 3,745원 | 3,662원 |
| 구독 ARPPU(월, 순, 수수료 15%) | 3,021원 | 2,894원 | 2,830원 |
| 구독 연매출 (수수료 15% / 30%) | 181만 / 149만 원 | 1,389만 / 1,144만 원 | 7,132만 / 5,873만 원 |
| 단품 연매출 (15% / 30%) | 83만 / 69만 원 | 668만 / 550만 원 | 3,004만 / 2,474만 원 |
| 보상형 광고 연매출 | 4만 원 | 71만 원 | 750만 원 |
| **1년 합계 (15% / 30%)** | **268만 / 222만 원** | **2,127만 / 1,764만 원** | **1억 887만 / 9,098만 원** |

**읽는 법**
- 매출의 대부분(약 65%)은 구독, 약 30%는 단품, 광고는 약 1.5~7%에 그칩니다. 광고를 늘리기보다 **스토리 연재량과 시즌 상품**이 매출을 좌우합니다.
- 기준 시나리오는 MAU 2만이 전제입니다. 마케팅 비용 없이 MAU 2만을 1년 평균으로 유지하기는 쉽지 않으므로, 1년차는 **보수~기준 사이**로 계획하는 것이 안전합니다.
- 연간 구독 1년 유지율 약 27~28% [11]을 감안하면 2년차 구독 매출은 신규 유입 없이는 크게 줄어듭니다.

## 9. 추가 검토 (2026-10-09): 불경 콘텐츠

- 불경(독경·경전) 콘텐츠는 **무료 미끼(짧은 독송·오늘의 한 구절·수행 도구·입문 1편) + 유료(해설 시리즈·전권 음원·PDF·경전 × 사찰 코스팩)** 구조로 검토했습니다.
- 원음 독경 단독은 질은 좋지만 무료 경쟁이 과잉이라 유료 상품으로는 약합니다. 해설·정확한 번역·출처가 붙은 콘텐츠가 유료에 맞습니다.
- 저작권(CBETA 비상업 전용, 한글 번역·음원 권리)이 가장 큰 선결 과제이며, 상세 내용은 `docs/scripture-content.md`에 있습니다. 권리 확정 전까지 앱에는 불경 음원·해설 상품을 넣지 않았습니다.
