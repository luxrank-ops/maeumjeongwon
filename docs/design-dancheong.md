## 1. 시안 → 이 앱

| 시안의 요소 | 절로가에서 | 연결된 기존 행동 |

## 2. 색

팔레트(⑮-1)만 바꿨다. 컴포넌트는 시맨틱 토큰을 부르므로 다른 화면(탐색·상세·지도·수첩·플래너·리포트)도 같은 톤으로 따라온다.

```
낮                                    저조도
--paper  #EEF2F8  청회색 바탕          --paper  #0B1120
--card   #FFFFFF  흰 카드              --card   #131B2E
--ink    #0F1B3D  남색 글자·굵은 테두리  --ink    #EEF2FA
--pine   #1A2C6B  주 행동(남색)         --pine   #7FA4FF  (위 글자는 어둡게 뒤집음)
--clay   #B4470F  주황 — 도장·기도      --clay   #FF9D5C
--gold   #8A5A00  노랑 — 이루었다       --gold   #F2C14E
```

- 새 토큰: `--hl*`(빠른 실행 바) · `--tile-*`(아이콘 타일 6색) · `--band-*`(권역 띠 4쌍) · `--stripe-*`(띠 왼쪽 색 줄) · `--fab-*`, 시맨틱 `--border-strong`.
  저조도 팔레트에도 같은 목록이 있어야 한다(`design-system` 3번).
- 대비: 본문·보조·강조 17쌍(`mobile-ux`) + 타일 글자 6쌍 · 띠 글자 4쌍 · 실행 바 2쌍 · 떠 있는 버튼 2쌍(`design-dancheong` 3번) 모두 낮·저조도 4.5:1 이상.
- 상태바는 흰 상단 바에 맞춰 `#FFFFFF`(저조도 `#131B2E`), 스플래시는 바탕색 `#EEF2F8`.

## 3. 글꼴

- 제목(h1·h2·h3)·워드마크는 **굵은 고딕**(900/800). 시안의 힘 있는 인상은 굵기에서 온다.
- 명조(`--font-display`)는 경전 구절(사경 시트)·이야기 본문에만 남겼다.

## 4. 움직임 · 접근성

- 공지 띠는 46초에 한 바퀴 흐른다. 두 번째 복사본은 `aria-hidden`. `prefers-reduced-motion` 이면 멈추고 가로 스크롤.
- 빠른 실행 칩·기능 타일·권역 띠·도구함은 모두 48dp 이상(`--tap`). 펼치기는 `<details>` 라 JS 없이 열린다.
- 떠 있는 상담 버튼은 `position:fixed` 가 아니라 본문 끝의 `sticky` — 하단 탭 위에 뜨고, 데스크톱 사이드 레일 배치에서는 오른쪽 아래로 간다.
