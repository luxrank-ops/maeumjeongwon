# 기도·기운 좋은 곳 — 추천 기준과 YouTube 자료

## 앱에 반영한 내용

- 탐색 테마와 여행 계획 필터에 **🕯️ 기도·기운 좋은 곳**을 추가했습니다.
- 기존 기도처·기운 테마의 21개 사찰을 한곳에서 살펴볼 수 있고, 사찰 상세에는 해당 사찰과 연결된 YouTube 참고 영상을 표시합니다.
- 여행 계획에는 영남(갓바위·불굴사·사리암), 서울(도선사·수국사·진관사), 남해(보리암·남해 용문사) 코스를 넣었습니다. 추천 카드에서 코스 사찰과 관련된 영상도 열어볼 수 있습니다.
- `js/data-prayer-videos.js`는 초기 공개 검색 스냅샷과 기존 사찰 참고 영상을 video ID 기준으로 합칩니다. 초기 통합본에는 총 **89개 영상 참조**가 있고, 영상 제목·날짜·유형·연결 사찰을 함께 둡니다. 새 검색 결과 수집은 `js/data-prayer-video-crawl.js`에 별도로 저장됩니다.

## 추천 기준

기도의 효험이나 이른바 영적 에너지는 앱에서 측정하거나 순위화하지 않습니다. 아래 신호를 분리해 여행 계획에 활용합니다.

1. **기도 전통·도량 맥락** — 사찰 공식 안내, 문화유산·백과사전, 불교계·언론 자료에서 확인되는 기도 대상·의례·순례 전통을 우선합니다. 출처와 전승 표현은 사찰별 기도 안내에 둡니다.
2. **YouTube 현장 자료** — 사찰명이나 기도처·전각·순례 경로가 제목 또는 공개 설명에 직접 나타나는 영상만 해당 사찰에 연결합니다. 세 곳 이상을 한 영상에서 다루면 각각 연결하되, 사찰 이름을 특정할 수 없는 지역 모음은 특정 사찰로 억지 연결하지 않습니다.
3. **자료 성격 표시** — 방송·뉴스·공공기관·문화 해설, 여행·산행 기록, 개인 풍수·효험 주장을 구분합니다. 개인의 경험·풍수 해석은 제작자 견해로만 표시하며 사실 확인이나 효험의 증거로 취급하지 않습니다.
4. **여행 안전·실용성** — 지역별 동선, 계단·산행 난도, 개방·입산통제 확인을 일정에 반영합니다. 실제 이동시간·운영정보는 방문 전에 사찰·국립공원 공지에서 확인해야 합니다.

**영상 수·조회수·검색 노출은 기운이나 영험함의 점수가 아닙니다.** 앱은 효험을 보장하거나 기도 서비스를 판매하지 않습니다.

## 조사 범위와 한계

- 초기 색인은 2026-10-11 공개 YouTube 검색 결과에서 확인한 제목·날짜·공개 설명의 사찰명과 기존 상세 데이터의 참고 영상으로 만들었습니다. 검색어는 `js/data-prayer-videos.js`에 기록되어 있습니다.
- 제목·공개 설명을 참고해 연결했으며, 영상 전체·비공개 자막을 전수 열람하거나 자막/영상을 다운로드한 것은 아닙니다. 검색 노출과 영상 공개 상태는 바뀔 수 있습니다.
- 검색 결과에 과장된 효험 표현이 있더라도 중립적인 자료 유형·주의 문구와 함께만 제시합니다. 불교학·문화유산 전문가 감수가 필요합니다.

## 선택 수집기

`tools/collect-prayer-videos.js`는 HTML 스크래핑 대신 **YouTube Data API v3**의 검색 메타데이터를 사용합니다. 사찰명 매칭 후 ID·제목·공개일·채널·검색어·사찰 ID만 저장하며 설명 원문이나 자막은 저장하지 않습니다. 검색은 관련도 순 상위 결과이므로 이것도 YouTube 전체 영상의 완전한 전수조사는 아닙니다.

```bash
YOUTUBE_API_KEY=본인_API_키 npm run crawl:prayer-videos
# 기본: 공통 7개 + 기도처별 21개 = 28개 한국어 질의, 질의별 첫 페이지 최대 50개
# 더 넓게: YOUTUBE_API_KEY=... npm run crawl:prayer-videos -- --pages 2
```

YouTube `search.list`의 관련도 상위 결과를 가져옵니다. 페이지 확장은 API 쿼터를 더 사용하므로 필요할 때만 늘리세요.

- API 키는 환경변수로만 전달하고 저장소에 커밋하지 마세요. API 콘솔의 사용량·약관·쿼터를 확인하세요.
- 수집 결과는 `js/data-prayer-video-crawl.js`만 갱신합니다. 수기 조사/기존 참고 영상과 화면 색인은 앱 로드 시 합쳐집니다.
- 메타데이터의 게시일은 API 반환 값입니다. 영상 삭제·비공개 전환 등으로 링크가 열리지 않을 수 있습니다.
- 테스트: `npm test` (수집기 연결·사찰명 매칭·중복 제거·테마 색인 검사 포함)
