# 전국 명당 사찰 풍수 대백과 — 정리 원칙 (2026-10)

`js/data-fengshui.js`에 담긴 「전국 명당 사찰 풍수 대백과」(`#/fengshui`)의 자료 수집·표기 원칙이에요.

## 무엇을 정리했나

- 「풍생풍사TV」(K풍수연구원 벽천 성영철) 현장 답사에서 소개한 **풍수 해설**(용맥·지기·장풍득수·형국론 관점의 명당 분석)을 앱 문체로 요약·재구성했어요.
- **권역별 18편**: 수도권 & 강원권 / 충청권 / 영남권 / 호남권. 각 편은 `형국` · `핵심 기운` · `풍수 해설` 세 가지로 구조화되어 있고, 해당 사찰 상세 페이지(`풍수 이야기` 카드)와 연결돼요.
- **목적별 맞춤 사찰 매트릭스 6종**: 재물·사업 / 입시·자격증·승진 / 위기 탈출 / 우환·악재·질병 / 힐링·재충전 / 신규 창업. 목적별로 최우선 추천 사찰과 풍수적 이유를 담아요.
- **사찰 방문법 3가지**: 시간대 선정, 뒤편 혈처에서 쉬기, 일주문부터 걸어 들어가기.

## 자료 취급 원칙

1. **요약·재구성만** — 원문 문장·대본을 그대로 옮기지 않고, 앱의 존댓말 문체로 다시 썼어요.
2. **외부 영상 미연결** — 유튜브 등 외부 영상 링크·색인·수집 도구는 넣지 않아요(기존 데이터 원칙 유지). 출처는 텍스트 표기로만 남겨요.
3. **효험 비보장** — 형국·기운 해설은 모두 개인의 견해이자 '전해지는 이야기'예요. 소원 성취·질병 치유 등 결과를 보장하지 않으며, 화면에도 같은 고지를 함께 보여요.
4. **사실과 해석 구분** — 주소·종단 같은 사실은 「전통사찰 현황」(2026.6.1.) 기준을 쓰고, 풍수 해석·설화는 '전해지는 이야기'로 표기해요.
5. **모르면 확인 필요** — 좌표·창건 연대 등 확인되지 않은 항목은 사찰 데이터의 `verify`에 「확인 필요」로 남겨요. (신규 수록 4곳: 양평 용문사·갑사·신원사·선운사)
6. **점수화 금지** — 영험함·기운을 점수나 순위로 매기지 않아요. 목적별 매트릭스도 '전해지는 해설 기준의 요약'일 뿐이에요.

## 연결 구조

- `window.FENGSHUI_ATLAS` — 권역·수록 편(형국/기운/해설)·고지·출처 표기
- `window.FENGSHUI_MATRIX` — 목적별 맞춤 사찰 매트릭스
- `window.FENGSHUI_VISIT_TIPS` — 사찰 방문법
- 사찰 데이터(`window.TEMPLES`)의 `fengshuiAtlas` 필드로 상세 페이지에 형국·핵심 기운 요약과 대백과 링크를 표시해요.
