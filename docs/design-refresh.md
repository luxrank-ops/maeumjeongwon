# 마음정원사 : 절로가 — 디자인 리뷰 & 리프레시 (2026-10)

"15년차 앱 디자이너가 이 앱을 손본다면 어떻게 했을까"를 구현한 기록이다.
목표는 예쁘게가 아니라 **이 앱이 해야 할 세 가지(마음을 고른다 · 사찰을 읽는다 · 걸어본다)가
첫 화면에서 한 번에 읽히게** 만드는 것이었다. 코드·문서에 남긴 판단 근거를 그대로 옮긴다.

## 2. 원칙 (이후 모든 화면에 같은 자로 대는 규칙)

1. **화면당 하나의 주 행동.** 홈 = "마음을 고른다". 나머지는 전부 보조.
2. **색은 3+1+1.** 종이 · 먹 · 소나무(주 행동) · 점토(도장·기도) · 골드(이루었다 전용).
   강조가 두 번 쓰지면 강조가 아니다.
3. **그림(아이콘)은 구조, 이모지는 내용.** 탭·버튼·제목에는 24px SVG 선 아이콘,
   기분·날씨·계절처럼 '그 자체가 내용'인 자리에만 이모지를 남긴다.
4. **글자는 최소 13px급, 본문 줄높이 1.6, 한글 자간 -.011em.** 영문 장식 라벨은 폐지.
5. **움직임은 정보 전달용.** 라우터가 화면이 바뀌었다고 표시한 때에만 진입 애니메이션,
   누름 피드백(1px)과 포커스 링. `prefers-reduced-motion` 전면 존중.
6. **상태를 색만으로 알리지 않는다.** 선택 = 표시줄+굵기+채움, 방문 = 도장+체크 아이콘.
7. **상업은 흐름의 끝에.** 상점·플러스·광고는 첫 화면 하단 한 장, 잠금은 "열 수 있다"는 사실만.

## 3. 바꾼 것 (구현 요약)

### 3-1. 셸 · 내비게이션
- `index.html`에 **24px SVG 아이콘 스프라이트**(`<symbol id="i-…">` 38종) 인라인.
  앱 JS의 `ic(name)`이 `<use>`로 참조 → 이모지·`grayscale` 필터 제거.
- 하단 탭: 선택 상태를 **위 표시줄 + 굵기 + 아이콘 stroke 두께**로. `aria-current="page"`를 라우터가 부여.
- 상단 바: `플러스` 칩을 그라디언트 금색에서 '골드 테두리 칩'으로 낮춤(구독 상태일 때만 채움).
  `본문으로 바로가기` 클래스 불일치 수정(`.skip-link`), `theme-color`를 `#f6f1e7`로 통일(manifest·SEO와 동일).
- 스크롤 시에만 topbar 경계(선·그림자)가 생긴다. 첫 화면을 무겁게하던 상시 그림자 제거.
- 서비스워커 `CACHE_NAME` → `maeumjeongwon-v3`, `features.js`도 버전 태그로 통일(스플릿트캐시 무효화).

### 3-2. 타이포 · 토큰 (⑮ 디자인 시스템 v3)
- `--font-ui` / `--font-display` 토큰. 로드하지 않는 웹폰트 이름은 앞세우지 않고,
  세리프가 없는 환경은 본 문체로 조용히 대체된다하도록 폴백 체인을 명시. SVG `<text>`는 변수를 못 읽으므로
  `DISPLAY_FONT` 상수로 동일 스택을 공유(108 염주 중앙 숫자).
- 자간 `-.011em`, 본문 줄높이 1.6, 마찰 최소: `.section-label`/`.eyebrow` 폐지 → `section-kicker`(한국어·13px급).
- 스케일 토큰: 여백 `--s1…--s6`, 모서리 `--r-sm/--r/--r-lg`, 그림자 2종, 포커스 링 `--ring`,
  이징·지속 `--ease/--dur-1..3`. 카드 안 카드는 배경 1단계(`--paper`)로만 구분.

### 3-3. 정보 구조 (홈)
`오늘 인사 → 마음 처방전(주 행동) → 매일의 리추얼 → 내 순례(결과) → 지금 가기 좋은 곳(가로 레일)
→ 여행 계획 → 쉬는 도구 → 읽을거리·상점 → 면책`
- 처방전은 선택과 결과를 한 카드에서: 기분 칩 → 처방 문장 → 사찰 한 줄 → `이야기 읽기`/`계획에 담기`.
- 등급·염주는 '내 순례' 한 장으로 압축(진행 바 + 미터 3개 + 다음 미션 한 줄). 다크 히어로 카드·장식 오브 제거.
- 계절 추천 + 많이 찾는 사찰은 **가로 스냅 레일**로 합쳐 세로 스크롤 3~4장 분량을 아낀다.
- 스토리·상점·플러스는 리스트 한 장(`읽을거리 · 내려받기`)으로. 홈 안의 광고 자리 없음.

### 3-4. 사찰 상세 = 행동 화면
- 하단 **고정 행동판**(sticky): `방문 인증`(주) · `길찾기`(보조). 모바일에서는 항상 손끝에,
  ≥1120px에서는 일반 버튼 줄로 풀린다(마크업 한 벌, CSS 두 벌).
- 그 외 7개 도구는 카드 안 리스트(`오디오 도슨트·AI 안내·수첩·계획에 담기·지도·스토리·오프라인`)로 위계화.
- 데모 체크인은 주 행동 옆에서 리스트 아래로 이동(테스트 수단이 정식 경로처럼 보인 문제).
- 확인 필요 항목은 경고 톤 카드(`.verify-card`)로, 출처·면책은 그대로 하단에.

### 3-5. 컴포넌트
- 버튼 3단계(`.btn` / `.ghost`·`.soft` / `.text`) + `.btn-group`(좁은 화면 자동 나눔),
  누름 피드백·포커스 링·`:disabled` 기준 충족(`min-height:48px`).
- 목록 행 `.titem`: 도장(印)은 원형 배지 → 각진 인장, 방문은 채운 인장 + 체크 태그, 행 끝에 화살표.
- 탐색 4단 탭은 크롤 칩 → **세그먼트 컨트롤(.seg)**. 전통사찰 검색은 흩어진 입력 3개 → `.searchbar` 한 덩어리.
- 시트 모달: 상단 그랩 핸들 + 항상 보이는 닫기 버튼(JS가 시트에 주입), 배경 스크롤 잠금 유지.
- 토스트: 먹빛 → 소나무 짙은 색, `prefers-reduced-motion`에서 멈춤.
- 잠금(`.locked`)·보상형 광고 안내는 예측 가능한 두 선택지로 나란히, 자물쇠 이모지는 아이콘으로.
- 빈 상태(`.empty`)·스켈레톤(`.skel`, 부트 화면·지연 데이터) 신설 — 기록 0개인 첫 사용자에게 다음 행동을 준다.
- `완료` 태그·진행률은 골드 1색, 위험(확인 필요)은 danger 톤. 색+아이콘+문자로 상태 표현.

## 4. 검증

- `npm test` — 100/100 통과. 반응형 가드(`server/test/responsive-layout.test.js`) 10개 전부 그대로 통과:
  5단 브레이크포인트, 셸 그리드, `--tap:44px`, 유동 `--fs-base`, `svh`·`env(safe-area)`,
  `data-flow=cards` 재배치 훅, 지도 리사이즈·모달 스크롤 잠금.
- `npm run test:content` / `test:temples` / API 스모크 전부 통과.
  기도 테마 가드 하나는 **제목의 이모지 의존**을 제거하도록 함께 손봤다
  (`'🧭 추천 기준'` → `'추천 기준'`) — 가드의 의도는 "추천 기준 카드가 그려지는가"이지 장식이 아니다.
- `npm run budget -- --check` — 첫 화면 gzip **132.0KB / 140KB** 통과.
  (스프라이트 인라인·새 CSS 레이어로 +7.8KB → 카드 안 카드 제거·`.tool-card` 등 죽은 규칙 정리로 일부 회수)
- 사각지대(정적 검사로 못 보는 것): 실제 브라우저에서 아이콘 정렬·시트 핸들·스티키 행동판의 가독성은
  기기별 확인이 필요하다. Playwright 스크린(`tools/test-*.js`)은 브라우저 설치 환경에서 다시 찍는다.
