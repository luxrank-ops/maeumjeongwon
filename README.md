# 마음정원사 : 절로가 (MVP 프로토타입)

전국 사찰의 기원·역사·전설을 이야기로 읽고, 순례 미션으로 모으고, 여행을 계획하는 사찰 순례·힐링 여행 앱의 정적 SPA 프로토타입입니다. 백엔드 없이 모든 기록은 브라우저 localStorage(`maeumjeongwon.v1`)에 저장됩니다.

## 실행
```bash
cd maeumjeongwon
python3 -m http.server 8642      # 또는: npx serve -l 8642 .
# 브라우저에서 http://localhost:8642  (모바일 화면 크기 권장)
```
GPS 인증은 브라우저 보안상 `localhost` 또는 HTTPS에서만 동작합니다. 지도 타일(OpenStreetMap)은 인터넷 연결이 필요합니다.

## 구성
- `index.html` — 앱 셸, 하단 탭(홈/탐색/지도/순례/수첩), 큰글씨 토글
- `css/style.css` — 따뜻한 한지 톤 모바일 우선 디자인, `body.big` 큰 글씨·간편 모드
- `js/app.js` — 해시 라우터, 마음 처방전, 탐색, 상세, GPS/데모 체크인, 미션·배지, 염주(108), 등급, 도감, 순례 지도, 사찰 수첩, 사찰 여행 계획(플래너)
  - 사찰 여행 계획 `#/planner` — 추천 코스 템플릿(사찰 테마별 필터 · 단풍·산행·바다·명상·설화·도심·기도·기운 좋은 곳)·준비물 체크리스트, `#/planner/new` 새 계획 짜기(경유 사찰 구성·동선 자동 정렬·거리/소요시간 추정)
  - 2026-10: **기도·기운 좋은 곳** 추천 테마에 영남·서울·남해 코스 추가. 기도 효험을 점수화하지 않고, 기도 전통·산행 안전·여행 실용정보를 구분
  - 2026-10: 새 계획 짜기 화면에 **🧹 초기화 버튼**(상단·저장 버튼 옆) 추가 — 확인 후 경유 사찰·제목·날짜·기간·이동 수단·동행·메모를 한 번에 비움. 지울 내용이 없으면 버튼이 비활성화되고, 저장된 여행 계획·수첩 기록에는 영향을 주지 않음. 작성 중 입력값은 사찰을 추가·삭제해도 유지되며, 계획을 저장하면 다음 새 계획은 빈 계획표로 시작
- `js/data-temples.js` — 상세 사찰 55곳 (좌표·종단·창건·문화재·연혁·전설·관람 포인트·풍수 이야기·확인 필요 항목)
  - 2026-10: 공개된 풍수 해설 자료를 참고해 풍수 이야기가 전해지는 암자·사찰 13곳 추가, 기존 12곳 보강 (풍수 해석은 개인의 견해·전해지는 이야기, 효험 보장 아님)
- `js/data-stories.js` — 심화 스토리 9편 (2026-10: 신규 4편 — 통도사 1·해인사 2·불국사 2·송광사 2, 기존 송광사 1편 사실 수정)
- `js/data-prayer.js` — 기도처·기운 좋은 사찰 조사(2026-10): 기도 안내(기도 대상·전승·방법·출처), 사찰별 테마, 공통 기도 예절, 탐색 화면의 추천 기준·한계 문구(`PRAYER_CRITERIA`·`PRAYER_LIMITATIONS`). 신규 테마 '🕯️ 기도·기운 좋은 곳' 추가
- `docs/prayer-theme-method.md` — 기도·기운 테마 추천 기준과 자료 수집 원칙: 기도 전통·자료 성격·여행 안전을 구분하고 영험함을 점수화하지 않으며, 외부 영상은 앱에 연결하지 않음
- `js/data-traditional.js` — 첨부 PDF「전통사찰 현황」(2026.6.1.) 991곳 전체 목록
- `vendor/` — Leaflet 1.9.4
- `docs/monetization.md` — 콘텐츠 전용 유료화 설계 v2(경쟁 분석·가격·페이월 지도·제작 로드맵·1년 매출 시나리오·법적 리스크)
- `docs/scripture-content.md` — 불경(경전) 콘텐츠 검토(2026-10): 시장 근거, 유형별 품질 분석, 저작권·번역·음원 조건, 무료 미끼 + 유료 상품 설계, 로드맵
- `tools/test-content.js` — 심화 스토리·보상 광고·콘텐츠 상점·순례 리포트 테스트, `tools/test-plus.js` — 플러스(유료화 데모)·기도처 테마 테스트, `tools/smoke-test.js` — Playwright 스모크 테스트/스크린샷, `tools/geocode.py` — 좌표 조회 스크립트

## 데이터 원칙
- 유튜브 등 외부 영상은 앱에 연결하지 않음 — 사찰 상세·추천 코스의 영상 링크·색인과 수집 도구는 2026-10 제거
- 전설은 모두 「전해지는 이야기」로 표기, 효험 보장 문구 없음
- 모르는 실용정보(주차·입장료·개방시간·교통·소요시간)는 「확인 필요」로 표기
- 출시 전 불교학·문화유산 전문가 감수 필요

## 마음정원 플러스 (유료화 프런트엔드 데모)
- 상단 `✨ 플러스` → 요금제(월 4,900원 / 연 39,000원, 7일 무료 체험), 무료 vs 플러스 비교, 자동 갱신·해지 고지
- 수익은 앱 안의 원작 콘텐츠로만: `#/store` 콘텐츠 상점(1회 결제 데모), `#/story/haeinsa-1` 심화 스토리(첫 장 무료), 보상형 광고 데모, `#/report` 나의 순례 리포트, `#/mind` 마음 처방전 심화(오락)
- **실제 결제 없음.** 체험·플러스 상태는 `localStorage['maeumjeongwon.v1'].plus`에 저장되는 데모 토글
- 소프트 페이월: 전설 2편째·풍수 2항목째부터, 테마 순례 코스 일정표, 🎧 오디오(기기 음성 데모), ⬇ 오프라인 저장, 계절 한정 스탬프
- 무료 유지: 탐색·지도·GPS 인증·스탬프·염주·도감·수첩·기도 안내/예절/출처
